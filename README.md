🚀 Mission Control

An interactive futuristic Mission Control web application built using
HTML, CSS, and JavaScript.

This project simulates a futuristic mission generator where users can
create a secret mission by selecting different mission components such
as agent type, location, weapon loadout, objective, and risk level. The
system then generates a complete mission briefing.

The project demonstrates core JavaScript concepts including variables,
arrays, functions, conditional statements, event listeners, and DOM
manipulation.

🎯 Project Features

Mission Selection System

Users can customize their mission by selecting:

-   Agent Type
-   Mission Location
-   Weapon Loadout
-   Mission Objective
-   Risk Level

Each category cycles through predefined choices using JavaScript arrays
and functions.

Mission Generator

The Launch Mission button generates:

-   Mission ID
-   Selected Agent
-   Selected Location
-   Selected Weapon
-   Selected Objective
-   Risk Level
-   Mission Status

The system validates that all selections are completed before generating
the briefing.

Random Mission Generator

Automatically creates a mission using random selections.

Reset System

Clears all selections and restores the application to its initial state.
